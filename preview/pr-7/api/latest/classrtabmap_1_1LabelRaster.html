Detailed Description

One node's labels per local grid cell (see LocalGridMaker::createLabelRaster()): a raster over the cells its label frames' points fall in, robot/base frame, each cell one label (1 byte): 0 seen with nothing there, 1-127 a label, 255 no vote. Saved with the node's occupancy grid (encode()).
