Detailed Description

The labelers of a labels image and the bits each has in a cell's 8-bit word (Parameters::kGridLabelers()): "floorseg:2 floorplan:6" packs. 

word = [ floorplan: 6 bits | floorseg: 2 bits ]

Labeler i is the labels image's channel i. A labeler's field is 0 for no vote (it did not judge the cell), else its label + 1; label 0 is seen with nothing there. A labeler of 0 bits stores nothing: its channel is an input only (Parameters::kGridGroundLabeler()).
