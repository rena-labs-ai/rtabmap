Detailed Description

One node's labels per local grid cell (see LocalGridMaker::createLabelRaster()): a raster over the cells its labelled points fall in, robot/base frame, each cell one 16-bit word of every labeler's label there, packed by a LabelLayout. Saved with the node's occupancy grid (encode()); the layout is the map's (Parameters::kGridLabelers()).
