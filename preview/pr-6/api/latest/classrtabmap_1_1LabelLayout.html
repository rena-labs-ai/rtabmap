Detailed Description

The labelers of a labels image and the bits each has in a cell's 16-bit word (Parameters::kGridLabelers()): "floorseg:2 floorplan:4 objseg:10" packs. 

word = [ objseg: 10 bits | floorplan: 4 bits | floorseg: 2 bits ]

Labeler i is the labels image's channel i. A labeler's field is 0 for no vote (it did not judge the cell), else its label + 1; label 0 is seen with nothing there.
